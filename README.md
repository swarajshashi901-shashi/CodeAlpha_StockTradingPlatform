# CodeAlpha Stock Trading Platform

An advanced Java Swing based Stock Trading Platform developed as part of the CodeAlpha Java Programming Internship.

## Project Overview

This application simulates a stock trading environment where users can view market prices, buy and sell stocks using virtual money, manage their portfolio, and track trading transactions.

## Features

- Simulated stock market
- Virtual starting balance of ₹1,00,000
- 12 predefined stocks
- BUY and SELL operations
- Portfolio management
- Average buy price calculation
- Market value calculation
- Realized and unrealized Profit/Loss
- Stock search
- Sector filtering
- Simulated market price movement
- Transaction history
- CSV transaction storage
- Input validation
- Java Swing graphical user interface
- Object-Oriented Programming architecture

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- Collections Framework
- File I/O
- CSV data storage

## How to Run

Compile:

javac -d out src/Main.java src/model/_.java src/service/_.java src/ui/\*.java

Run:

java -cp out Main
